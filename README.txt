MOMENTUMBOT_AI public website starter

1. Review all wording in index.html before publication.
2. Publish ONLY this public site folder, never your FastAPI backend, .env, database files, credentials, or private trading strategy code.
3. On GitHub, create a NEW public repository (e.g. momentumbot-ai-site) and upload index.html and robots.txt into its root.
4. In repository Settings > Pages, select 'Deploy from a branch', main, / (root), Save.
5. Visit the public GitHub Pages URL shown in Settings > Pages after publishing.
6. Optional: Purchase a domain if available; configure that custom domain through your site hosting provider and GitHub Pages settings.
7. After the final website URL is known, add a sitemap.xml using full published URLs, then add `Sitemap: https://YOUR-DOMAIN/sitemap.xml` to robots.txt. Do not publish placeholder URLs in a sitemap.
8. Register your final site URL with https://search.google.com/search-console/ , verify ownership, and submit URL Inspection > Request indexing. Add the sitemap via Sitemaps if configured.
9. Check search appearance and indexing regularly. Google does not guarantee inclusion.

Current starter is a static promotional site only, with no form, login, or financial execution capability.
